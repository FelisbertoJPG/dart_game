# 🐦 DashLingo: Aprenda Flutter Voando!

DashLingo é um jogo mobile gamificado inspirado no Duolingo, focado em ensinar **Dart e Flutter** de forma divertida, interativa e eficiente. 

## 🚀 O Projeto

O DashLingo transforma o aprendizado de programação em uma jornada. Com uma trilha de aprendizado visual (Path Map), os usuários desbloqueiam módulos conforme dominam conceitos fundamentais do Dart, progredindo até a criação de interfaces complexas em Flutter.

### Principais Características
- **Trilha de Aprendizado Estilo Mapa**: Navegação visual que rastreia seu progresso.
- **Motor de Quiz Inteligente**: Questões que se adaptam ao seu desempenho. Errou? A questão volta no final da rodada para garantir a fixação.
- **Gamificação**: Sistema de corações (vidas) e ganho de XP.
- **Foco em Lógica**: Currículo denso focado em tornar você um mestre em Dart antes mesmo de tocar nos Widgets.

## 🛠️ Tecnologias
- **Flutter** & **Dart**
- **Riverpod**: Gerenciamento de estado robusto e escalável.
- **Google Fonts (Outfit)**: Tipografia moderna e premium.
- **Lottie**: Animações fluidas para feedback do usuário.

## 📁 Estrutura do Repositório
O projeto segue uma arquitetura modular e organizada:
- `lib/core`: Temas, constantes e utilitários globais.
- `lib/features/modules`: Gestão da trilha de aprendizado e dados do currículo.
- `lib/features/quiz`: Motor interativo e UI dos desafios.
- `lib/features/profile`: Gerenciamento de progresso, XP e corações.
- `docs/history`: Documentação detalhada de cada fase de implementação (**Dev Logs**).

## 🏁 Como Rodar
1. Certifique-se de ter o Flutter instalado (`flutter doctor`).
2. Clone o repositório.
3. Execute `flutter pub get`.
4. Rode o projeto com `flutter run`.
